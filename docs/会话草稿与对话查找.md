# 会话草稿与对话查找

商品运营的每个会话保留独立输入草稿，新建对话也有单独草稿。切换商品后会载入对应的输入内容，侧栏显示“草稿”标记，便于回到尚未写完的会话。

普通草稿保存在当前浏览器标签页，刷新后可继续写，按登录用户隔离，保留最近50份、24小时内的草稿；关闭标签页会结束这份存储。页面提示“草稿已保存到当前标签页”表示已保存。检测到密钥标记、链接、密码、提取码或交付文字时只在页面内存保留，刷新后清除，并显示对应提示。浏览器存储失败时仍可继续输入，提示改为“草稿在当前页面保留”。草稿保存不会调用模型、创建任务或提交商品。

发送后可继续输入下一条。请求失败时，输入框为空则恢复本次发送内容；已有新草稿时保留新草稿，并单独展示未完成消息。切换会话后返回，请求失败恢复的内容仍属于原会话。从其他面板触发对话命令时，输入框里尚未发送的文字保留。指令已成功处理而后续结果读取失败时，仅提示刷新查看，避免将已完成指令当作发送失败重新填回输入框。

点击会话顶部的放大镜查找当前已加载的消息；焦点在商品运营页面内时，也可使用 Ctrl+F 或 ⌘+F。输入关键词后显示匹配消息数并高亮，使用上下箭头、Enter、Shift+Enter 切换位置，Escape 关闭查找。搜索按字面匹配，排除内部工具步骤与已被后续结果替代的消息。当前接口最多加载最近400条事件，查找范围以页面已加载的可见消息为准，当前功能不会搜索所有历史会话。

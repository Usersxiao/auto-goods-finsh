# 多账号同步发布审核

在商品预览中点击「同步发布」，选择要使用的账号。桌面左侧搜索和选择账号，右侧逐账号审核；手机可以收起账号设置，集中查看商品内容。底部确认操作保持可见。

## 完整审核

- 可搜索账号名称或 ID，批选筛选结果，单次最多选择 20 个账号。搜索保留其他已选账号；离线账号禁止新选，达到上限后仍可取消已有选择。
- 每个新建发布账号展示完整标题、详情、售价、平台分类、所在地、当前版本与北京时间排期；立即发布和定时发布分开说明。
- 图片可逐张切换，视频可播放预览；视频实际发布能力遵循原项目的账号限制。素材加载失败可以切换素材或更新审核单重试。
- AI 回复与自动发货分别展示本次选项、模型、卡券名称与账号级开关影响。跳过的功能保留原规则。审核不展示私密交付正文或模型密钥。
- 顶部汇总新建发布、复用记录和待完善账号数量。任一账号存在缺项时整组等待完善，保留全部所选账号。

已发布、已确认排期、正在上架和结果待核对的账号沿用已有记录。这些账号展示原任务状态及可用的商品链接，跳过本次新建发布及托管配置。新草稿和新排期不会冒充原商品内容；原商品、排期和托管结果通过「发布进度」查看。全部账号均为复用记录时，确认按钮明确显示「确认保留记录」。

## 发现缺项后直接修改

新建发布账号的审核区提供「完善共用商品」入口，可以修改文案和价格、共用分类与所在地、AI 回复和发货托管开关，以及选择或新建发货卡券。修改保存到原商品草稿，供本次新建发布账号使用；复用账号的原商品、原排期与托管记录继续保留。

保存或取消编辑后自动返回同步审核，保留全部已选账号、显式选择的同步接口（包括留空使用账号现有配置）、当前查看账号、账号搜索条件和手机端设置区的展开状态。返回时重新读取原商品和所选账号审核单，清空旧确认，再由卖家核对发布。

共用设置中集中调整分类、所在地和托管选项；同步目标账号和 AI 接口仍在同步审核页选择。设置页隐藏重复的账号、发布模式与模型接口选择，保存保留原商品的账号和发布模式。若从共用设置进入卡券选择，保存卡券后仍回到原同步审核。

原商品已提交发布、已确认排期或仍在生成时，不在同步审核中改动原内容；回到原商品运营核对后再处理。普通可编辑草稿保留原有内容版本校验和未保存保护，离开同步审核修改共用内容前也会保护未保存的模型接口草稿。

设置读取失败时可以在原处重试读取共用设置，或返回原同步审核。修改已保存但返回审核读取失败时，只重新读取审核内容；同步审核单读取失败时保留账号、接口和搜索选择，可点击「更新审核单」重试。以上读取和保存不会发起发布；发布仍须重新勾选并确认。

## 审核有效性与恢复

审核单保存读取时的商品内容、版本、排期及所选账号与模型。商品、价格、素材、卡券、排期和流程等待条件变化后，保留原预览、撤销确认并要求更新审核单；轮询时间和普通对话变化保留确认。

账号或模型更换后自动核对新审核单；请求途中暂停提交，迟到响应忽略。读取期间商品变化时拒绝旧结果。读取失败保留已有审核内容，点击「更新审核单」重新读取即可，重试读取不会发布商品。

新增模型接口的未保存内容会暂停发布，关闭时提供继续编辑或放弃修改的选择。保存并使用新接口后，重新生成所选账号审核单；模型列表仍可从新增接口中拉取。

确认仅提交与当前审核单匹配的账号、版本、模型引用和服务端审核指纹。服务端在提交时再次检查，前端同时阻止重复点击。提交期间保留面板并暂停账号、模型修改与关闭；失败后须更新审核单再确认。成功后自动进入「发布进度与结果」，分别查看每个账号的实际上架与托管情况。

## 验证范围

生产构建和模拟浏览器验证覆盖完整预览、各类复用状态、托管组合、20 账号上限、搜索批选、审核失效、读取失败与迟到响应、模型草稿保护、异常审核单、重复点击、提交失败恢复、结果页衔接、手机和暗色布局。模拟接口拦截所有 API 请求，不触发真实上架、消息发送或订单操作。

完整审核页的 101 项模拟检查已通过，包括连续 6 次输入后立即按 Esc 的未保存保护，以及经营设置中共享模型组件的退出回归。模型草稿在布局阶段同步给父级，避免紧接着退出时丢失输入。

共用修改往返流程新增 65 项模拟检查通过，覆盖文案、价格、分类、托管、已有与新建卡券、第二版文案、留空接口选择、未保存保护、保存冲突、读取恢复、设置迟到响应、复用账号保留、手机与暗色布局、原单品审核回归，以及修改后的防重复提交和结果页衔接。

# 对话审核卡片

在商品运营对话里说“发布当前商品”“同步发布到账号A和账号B”“整批排期顺延一天”或“重新准备当前商品”等指令，生成审核单后，输入框上方会出现待审核卡片。重新打开同一会话或刷新页面，可以继续查看这张卡片。

点击“查看审核”，检查商品、账号、售价、文案、图片、视频及操作范围，勾选确认后执行。文案优化和版本恢复会展示修改前后的内容；批量操作逐件展开查看。点击“继续修改”返回对话，输入框里的文字保留；“取消”撤销本次待确认操作，保留商品内容和已有排期。

支持商品发布、多账号同步发布、批量定时发布、调整发布时间、重新准备商品、恢复版本、应用文案优化和更换发货卡券。卡券审核只显示绑定前后的名称，发货原文通过“查看发货卡券原文”核对。

审核单有效期为30分钟。过期后在对话里重新生成，或取消旧审核单。内容、账号、托管配置或排期变化时，确认前会重新校验。每次新建审核单都有独立标识；旧窗口的确认或取消请求会提示刷新，避免操作到新审核单。并发确认只消费一次当前会话的审核记录，平台发布继续复用原有的防重与结果核对机制。

## 接口

- `GET /api/v1/operations/jobs/{job_id}/confirmation`：读取当前待审核摘要，无执行快照或发货原文。
- `POST /api/v1/operations/jobs/{job_id}/confirmation/review`：提交 `token` 获取完整审核内容，并检查原审核范围与最新状态。
- `POST /api/v1/operations/jobs/{job_id}/confirmation/apply`：提交 `token` 和 `confirmed: true`，再次校验并调用已有业务服务。
- `POST /api/v1/operations/jobs/{job_id}/confirmation/cancel`：提交 `token`，只取消与该标识对应的待确认操作。

接口沿用当前登录用户的归属校验，审核列表采用字段白名单，排除Cookie、接口密钥、内部执行快照和发货原文。线上商品编辑仍会在实际提交前读取平台当前内容进行校验；结果待核对时沿用现有处理流程。

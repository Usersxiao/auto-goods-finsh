# 多账号会话导航

商品运营左侧会话列表显示当前文案版本的标题、发布账号、自动或审核模式，以及下一步需要做的事。已上架或发布结果待核对的商品以原发布账号和快照标题为准；明确发布失败的商品则展示当前调整后的账号与文案。

可以用账号下拉框筛选，也可以同时搜索商品标题、关键词、账号昵称、账号 ID、任务 ID 或下一步提示。多个搜索词以空格分隔，全部匹配才显示。未选发布账号、原账号已移除的历史会话分别保留入口。昵称只从当前登录用户的发布账号选项取得。

状态分为全部、进行中、待处理、已发布、已停止。计数随账号和搜索条件变化；待处理包含需要补素材、审核、恢复执行、核对发布结果及完善已发布商品托管的会话。因此一件已发布但托管待完善的商品也会出现在待处理中。空白对话不计为待审核。审核单过期时提示重新生成，不直接执行旧审核。

筛选仅改变列表，当前打开的会话、发布账号与输入草稿都保留。当前会话被过滤时会显示提示，点击“显示当前会话”即可清除筛选。筛选后新建对话仍使用原来的新会话账号设置；具体发布目标以对话顶部账号及发布审核单为准。

侧栏显示最近活跃的 50 个主会话，按最后更新时间排序；重新操作的旧会话可回到列表顶部。多账号同步的子任务继续归在原商品内。日期分组与列表日期统一使用北京时间。完整商品查询仍可通过“商品工作台”进行。

后端 `conversation` 字段只投影标题、发布账号 ID、发布模式、下一步提示及待处理标志；排除完整研究数据、发货内容、接口密钥和执行快照。读取会话列表不会消费审核单，也不会触发发布、恢复或发货。

验证：`operations/tests/test_conversations.py` 覆盖主会话归属、私密字段隔离、大研究数据、更新时间与数量限制、文案版本、已发布快照、过期审核、状态提示及读取不写入。浏览器验证覆盖账号与状态组合筛选、隐藏当前会话的提示、草稿保留、手机抽屉和暗色布局。

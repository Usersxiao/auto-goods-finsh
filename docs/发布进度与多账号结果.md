# 发布进度与多账号结果

商品运营对话中新增精简的「发布进度」卡片，点击可展开各账号的上架、定时和托管结果。主商品和同步商品合并展示，同一任务只计一次。原先逐条展开的同步结果列表收进这个面板，减少对话中的重复信息。

## 入口与状态

- 单商品审核提交或同步提交成功后，自动打开结果面板；提交任务和实际上架分开显示。
- 预览区域在已上架、已确认排期、正在上架或结果待核对时显示「查看发布进度与结果」，沿用原发布记录。
- 结果支持全部、待处理、处理中、定时、已上架筛选。已上架商品的托管异常也归入待处理，所以待处理数量可与已上架数量重叠。
- 选择一个账号后读取该任务详情，核对账号 ID、商品链接、北京时间排期和当前异常原因；未选择的同步任务不提前逐个读取全文。

桌面使用账号列表与详情并排布局；手机将账号选择固定在结果面板顶部，切换账号时直接从详情开头查看，底部返回入口保持可见。

## 上架与托管分别核对

商品上架成功后，AI 回复关联与自动发货关联分别展示保存结果。实际返回启用的项目显示已完成，跳过的项目明确标注保留账号原有开关与规则；缺少结果时保留待核对状态。自动发货关联表示交付配置已保存，订单实际发送情况仍需查看发货记录。

商品已上架但托管未完成时，可重试托管配置并显示错误原因；发布结果待核对时，可核对原发布记录。这两项使用现有处理接口，沿用原商品记录，不重新提交上架。按钮拦截重复点击，操作期间暂停切换账号和关闭面板。

排期中的商品可跳转查看或调整排期；错过时间的商品先重新安排。发布失败或条件待完善的商品可直接进入商品检查。各账号都可以打开自己的运营对话，也可进入运营待办继续处理。

## 读取与恢复

记录定期刷新，切换账号后忽略上个账号迟到的详情响应。读取失败时保留已有记录、展示错误和刷新入口，暂停依赖该结果的处理按钮。页面重开后从服务端恢复实际状态，结果面板本身不产生额外发布任务。

## 验证

前端生产构建和模拟浏览器验证覆盖：主商品去重、多账号状态筛选、托管开关组合、北京时间排期、配置重试、未知结果核对、重复点击、失败读取重试、账号切换隔离、单商品及同步提交后的结果入口、手机与深色界面。测试使用模拟接口，不发送真实商品或订单操作。

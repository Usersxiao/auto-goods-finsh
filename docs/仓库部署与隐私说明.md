# 仓库部署与隐私说明

本仓库是当前源码的独立快照，保留上游 LICENSE 和第三方图标许可，不包含原仓库的 Git 历史、本机账号或运行数据。

## 本地启动

1. 安装 Docker Desktop、Node.js 20 及兼容的 npm。
2. 将根目录 `.env.example` 复制为 `.env`，填写独立的 MySQL、Redis 密码。示例文件中的空密码需要填写。
3. 将 `compose.local.example.yaml` 复制为 `compose.local.yaml`，按本机路径和平台检查配置（示例为 Apple Silicon 的 `linux/arm64`）。默认只绑定本机端口。
4. 执行 `npm ci --prefix frontend` 和 `npm run build --prefix frontend`。
5. 执行 `docker compose -f docker-compose.yml -f compose.local.yaml up -d --build`，从此源码构建并启动服务。
6. 打开 `http://localhost:9000/product-operations`。账号、Cookie、模型接口与发货卡券均需自行配置。

# 连续任务与批量审核

## 一次交代整件事

打开商品运营，可以直接说：

> 应用经营模板「口播源码」，读取 /Users/your-name/Desktop/咸鱼素材/11.8，生成三套封面，使用第2套，明晚8点发布。

已有关键词和研究的商品会继续利用保存进度；新对话套用模板后，沿用模板对应的商品关键词。系统保存整条待办，商品生成完成后继续做封面与排期。仅要求“生成三套封面”会留下候选；明确指定“使用第2套”才替换发布封面。

上方任务卡显示完成数和当前状态，展开可看待办事项。可以说：

> 查看整条任务
>
> 暂停整条任务
>
> 继续整条任务
>
> 取消剩余步骤

暂停保留进度，继续沿用已完成步骤。取消剩余步骤保留商品内容，后续交给你审核。

审核模式下，整条任务完成后等待确认。自动模式下，全部准备完成并且发布条件齐备后，再按排期执行。连续准备过程中会暂缓发布，避免文案刚生成就提前使用旧封面上架。相对日期在接收时固定下来，按北京时间计算。

模型或采集失败时保留待办。手动修改了商品后，后续步骤会先暂停，核对后再继续。项目在等待生成时重启，可自动接着检查；若正好在执行某一步时中断，系统提示你先核对该步骤结果，再继续。

## 一批商品集中审核

先用原排期功能安排多个素材文件夹和各自时间，系统提前生成商品。然后说：

> 打开批量商品审核台

也可以点击顶部日历图标，或排期卡片内的审核入口。

1. 选择排期批次，逐件查看完整文案、图片视频、价格、账号和时间。
2. 标题、详情、价格可直接修改；“分类与托管”可调整当前商品的账号、分类、所在地、AI 接口和回复／发货开关；“发货卡券”可选择已有卡券或新建文字卡券。更换封面等操作仍可点“打开运营”继续交代。
3. 取消勾选某件商品即可跳过。尚未就绪的商品显示原因，保留草稿等待处理。
4. 勾选发布与托管确认，再点击“确认 N 件商品排期”。

只提交选中商品，未选商品保留原状态。提交后等待各自发布时间，到点上架。修改过内容、账号或卡券的旧审核单会失效，需要重新检查。确认单30分钟有效。

### 刷新、修改与提交核对

- 刷新审核单时保留当前预览、搜索条件和全部已选商品；读取失败后可继续查看原内容，再点击刷新重试。批次列表读取失败有独立重试入口。
- 已选商品的售价、账号、排期、内容或托管设置有变化，会列出更新说明，并撤销此前的勾选确认。切换批次时重新建立该批次的审核范围。
- 商品变为未就绪、已安排发布，或已从本批次移出时，保留原选择并列出具体原因。请先处理问题，或点击“移出本次选择”，然后再确认。新变为就绪的商品需自行加入本次选择。
- “核对最终清单”按账号分组，展示完整标题、售价、含年份的北京时间、AI 模型和发货卡券。筛选外已选商品仍会一起提交，页脚会明确提示件数。
- 审核单过期或所选商品的发布时间已过去时，确认会自动撤销。修改后成功保存但重新读取失败，只需刷新审核单；已保存内容和选择均保留。
- 提交报错后先刷新核对实际排期状态，再重新审核。请求中断时，服务器可能已接受排期；页面保留选择供核对，避免直接重用旧审核单。提交成功后清空本次选择，其余待审核商品保留。

审核台内编辑有未保存提醒，切换商品、刷新、关闭时可选择保存、放弃或继续编辑。小屏支持放大预览；屏幕高度不足时，审核区整体滚动，预览与底部操作区保持正常排列。

### 在审核台内调整账号与卡券

打开“分类与托管”或“发货卡券”会按当前预览的任务 ID 读取最新商品，独立于后台的运营对话。设置页标明当前商品；保存只作用于这一件。调整 AI 接口时可以复用配置，也可以新增接口并拉取模型。

保存或取消后返回原批次，保留全部选择、搜索、账号和状态筛选，以及列表或放大预览状态；重新读取审核单，并撤销旧勾选确认。换账号后，如果商品被原筛选隐藏，可点击“查看刚修改的商品”，直接清除筛选并定位到该商品。明确清空过的选择会继续保持为空。

设置与卡券的未保存内容受离开提醒保护；从设置转到卡券也会先处理未保存内容。保存失败可留在原处重试。设置读取失败时可以单独重新读取，或返回批量审核；已成功保存但审核读取失败时，仅重读审核单，避免重复保存或重复新建卡券。

已在执行、已确认排期或发布结果待核对的商品，先返回审核台刷新状态，再按对应入口处理；已有发布保护继续生效。

定时执行需要电脑唤醒、Docker项目运行、发布账号登录。排期按北京时间显示；平台实际处理仍需要时间。

# 长对话阅读与新回复导航

商品运营为每个会话记住阅读位置。第一次打开停在最新消息；上翻查看历史后，切换到其他商品再返回，或刷新页面，会恢复到原消息与段落附近。手机和桌面布局切换时，以消息 ID 与相对位置恢复，减少重新寻找内容的时间。

上翻时，消息区域底部提供“回到最新”。有新增或更新的助手回复时，增加“几条新回复”入口，点击定位第一条尚未查看的结果。回到最新或手动滚动到底部后清除计数。第一条新回复本身已位于底部时，定位也会清除计数。底部阅读时继续自动跟随新内容。

计数依据实际显示的助手消息。自己的消息、隐藏工具步骤、导入历史及单纯任务状态变化不计入；同一条助手回复连续更新只计一次，同一轮被新版替代的旧结果从计数中移除。上翻阅读、查找消息时，新回复不强制打断当前阅读；从查找继续发送指令会关闭查找并回到最新进度。

阅读位置和未读消息 ID 只保存到当前标签页的 `sessionStorage`，按登录用户隔离，最多 50 个会话、24 小时有效。存储只包含消息 ID、偏移、滚动位置和时间，不包含消息正文、交付链接或接口配置。浏览器存储受限时，仍在当前页面内记忆。原消息已超出接口加载范围时，使用保存的滚动距离回退；此功能不扩大原接口的历史消息范围。

新回复导航放在消息区域内，随着输入框和审核卡片高度调整，避免遮挡输入或发送按钮。读取失败时保留位置记录；恢复读取后继续定位。阅读导航不会暂停或恢复任务，也不会发布、发货或改变商品账号。

验证使用模拟接口覆盖长会话切换、刷新恢复、未读更新与替换、隐藏事件、手机重排、消息查找、准确发送归属、存储受限、过期、用户隔离和历史锚点缺失。前端构建包含 TypeScript 检查。

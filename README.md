# 闲鱼 AI 商品运营与自动化系统

通过对话完成商品研究、素材整理、文案生成、定价、多账号上架和定时发布，在同一后台管理 AI 回复、订单议价、卡券发货与经营反馈。

## 功能概览

| 模块 | 功能 |
| --- | --- |
| AI 商品运营 | 关键词采集、Hot100 样本分析、素材读取、商品方案生成、审核与发布 |
| AI 自动回复 | 商品知识、上下文问答、自然聊天、模型配置复用、异常恢复 |
| AI 议价与订单改价 | 议价轮数、优惠边界、最低成交价、待付款订单改价与结果核对 |
| 自动发货 | 固定文字、批量卡密、图片、API 卡券、商品绑定与补发记录 |
| 多账号管理 | 账号登录、Cookie 维护、连接状态、账号独立配置与同步发布 |
| 商品发布 | 素材库、单品发布、批量发布、定时发布、地址库与发布记录 |
| 在线聊天与规则回复 | 多账号会话、消息收发、文本／图片／API 关键词、默认回复与消息过滤 |
| 订单管理 | 订单同步、状态跟踪、发货记录、自动评价与异常核对 |
| 商品采集与监控 | 关键词查询、商品采集、分类监控与采集记录 |
| 经营分析 | 店铺指标、本地订单与咨询统计、商品表现、文案优化与版本对比 |
| 分销与返佣 | 货源、商品对接、分销卡券、返佣选品、素材与发布规则 |
| 后台管理 | 数据概览、用户权限、通知渠道、黑名单、风控日志与定时任务 |
| 移动端 | 消息、订单、商品、账号、卡券与 AI 上架等功能入口 |

## AI 商品运营

后台「商品运营」把研究、生成、预览、发布和后续管理放在同一会话中。对话展示处理结果与待确认事项，侧栏用于切换商品，预览区用于核对实际准备发布的内容。

### 商品研究与内容生成

| 功能 | 说明 |
| --- | --- |
| 关键词采集 | 按商品关键词采集候选商品，保存已完成进度 |
| Hot100 研究 | 按本次采集到的有效热度字段排名，分析标题、卖点、详情结构和标价 |
| 竞品文案分析 | 提炼共性表达、差异卖点和购买顾虑，保留实际样本与研究依据 |
| 本地素材读取 | 读取指定目录内的图片、视频、说明文档与压缩包文件清单，支持图片 OCR、PDF 和 Word 文本提取 |
| 商品事实整理 | 从材料中整理交付内容、使用方式和售后范围，缺失信息提示补充 |
| 多版文案 | 生成三版标题与完整详情，可通过对话扩写、精简、修改卖点或切换版本 |
| 自动定价 | 结合有效样本标价、成本与售价边界给出建议；样本不足时标注试售价与依据 |
| 分类匹配 | 根据商品内容匹配平台推荐分类，并提供核对和调整入口 |
| 图片与视频 | 添加或删除媒体、设置封面、调整图片顺序，保留当前文案和发货配置 |
| 封面制作 | 用已有图片与商品事实合成三套不同配色的封面，选中后加入发布预览 |

Hot100 表示本次有效采样的热度榜，样本不足时按实际数量展示；研究依据包括公开热度与标价，竞品真实销量和实际成交价另行核实。素材读取仅处理已配置的本地目录，源码只登记清单。

### 预览、审核与自动发布

- 手机商品详情式预览展示标题、价格、完整详情、图片和视频，实际显示以闲鱼客户端为准。
- 发布总览集中核对目标账号、分类、所在地、价格、排期、模型和发货卡券。
- 交付预览单独展示付款后买家收到的内容；预览时保留卡密库存，公开商品文案与私有交付内容分开管理。
- **审核模式**：先生成商品方案，审核文案、素材、回复和发货设置，确认后提交发布。
- **自动模式**：明确选择后，系统在目标账号、商品内容和发布条件齐备时提交发布，或等待已设置的时间。
- 文案、价格、账号、卡券等内容发生变化后，原确认失效，需要按最新内容重新核对。
- 发布记录保存每次提交结果；结果待核对时先检查原记录，避免重复上架。

普通卖家发布接口以图片为主，鱼小铺可发布视频。预览与审核会提示当前账号的媒体发布能力。

### 多账号与模型配置

- 每件商品明确选择发布账号，预览和确认单显示本次目标。
- 同一商品可同步发布到其他账号，共用当前审核的文案、价格和素材，逐账号核对分类、所在地、模型与发货条件。
- 发布结果按账号保存，失败账号可单独处理，已成功的记录继续保留。
- AI 配置支持复用现有账号配置或共享接口，也可新增 OpenAI 兼容、Anthropic、Gemini 接口，拉取模型列表后选择模型。
- 发布后按已选设置关联商品知识和发货卡券；AI 回复与自动发货可分别开启或跳过本次配置。
- 账号级模型及开关会影响该账号的其他商品，审核时显示对应影响范围。

### 批量素材与定时发布

- 一次交代多个素材文件夹、各自发布时间和发布账号，为每个目录生成独立商品。
- 单批支持 1～50 个目录，可复用研究结果，分别生成文案、定价和素材方案。
- 支持明确日期以及「明天 20:00」「下周一」等时间表达，排期与确认单按北京时间展示。
- 审核模式下集中检查整批商品，逐件修改文案、账号、分类、模型和卡券后确认排期。
- 发布日历可按账号、批次和状态查看安排，支持整批顺延、提前或按间隔错开。
- 支持暂停、继续、改期和取消排期，已完成的研究与草稿保留。
- 排期保存在服务端，关闭网页后继续处理；执行时需保持电脑唤醒、服务运行、素材可读与账号登录。

### 工作台、模板与版本

- **商品工作台**：按账号、标题、商品 ID 和配置缺项筛选，继续处理已有草稿或已同步商品。
- **经营模板**：复用商品事实、文案要求、价格边界、卡券、AI 接口引用和所在地，目标账号按商品选择。
- **连续任务**：一次交代读取素材、生成商品、制作封面和安排发布，逐步保存进度，支持暂停与继续。
- **版本记录**：生成、修改文案或价格、调整媒体时留档，支持命名保存和前后对比。
- **版本恢复**：核对差异后恢复未发布商品的内容与素材，恢复后重新审核发布或排期。
- **会话导航**：按账号、商品和状态查找，保留输入草稿、历史记录与阅读位置，支持消息查找。

### 发布检查与经营优化

- 发布前检查商品事实、文案、价格、素材、账号与托管条件，缺项直接进入对应修改入口。
- 上架后核对可读取的标题、详情、售价、媒体数量，以及 AI 回复和发货配置的关联情况。
- 运营待办集中展示准备中断、发布失败、错过排期、结果待核对、上架差异与托管待完善。
- 从验收报告直接配置 AI 回复、检查发货卡券、查看原发布账号与逐条发货规则。
- 发布成功后配置托管失败，可单独重试回复与发货配置，沿用原上架结果。
- 汇总店铺曝光、访问、咨询、支付、退款，以及本地订单与咨询记录；缺失字段保留为缺失。
- 根据现有商品事实、研究和可核对的经营反馈生成文案优化方案，展示完整前后对比，审核后应用。

## AI 自动回复与议价

### 商品问答与自然聊天

- 使用当前商品的交付内容、教程、使用方式和售后资料回答问题。
- 按真实问答顺序保留上下文，区分商品咨询、普通闲聊、技术问题与议价请求。
- 简单问题简短接话，复杂问题按需解释，减少重复自我介绍、固定结尾和无关推销。
- 保留账号自定义说明与商品独立知识，新增商品可在上架后接入对应知识。
- 支持关键词、默认回复与 AI 回复配合，按已有消息过滤、黑名单和人工接管规则处理。
- 模型超时、限流或空回复时保存恢复任务，按有效期重试；新消息和人工接管会更新旧任务状态。

### 议价与订单改价

- 设置最高优惠比例、最大减价金额和实际让价轮数，普通询价独立处理。
- 商品发布、定价和议价共用成本与最低成交价约束。
- 核对账号、商品、买家及待付款订单后申请平台改价，核实成功后再按新价格引导付款。
- 改价失败保留原因并进入结果核对，后续 AI 问答按当前有效设置继续处理。

## 自动发货与卡券

| 类型 | 用途 |
| --- | --- |
| 固定文字 | 网盘交付说明、提取码、使用步骤等固定内容 |
| 批量卡密 | 按库存分配不同卡号、兑换码等内容 |
| 图片 | 按卡券配置发送交付图片 |
| API | 按接口配置请求交付结果 |

- 在商品对话中搜索、选择已有卡券，或创建新的文字卡券并绑定商品。
- 商品发布后关联对应卡券；已上架商品也可审核后换绑，保留原商品与发布记录。
- 按账号设置处理自动确认发货、延迟、补发及禁止发货规则，保留交付和失败记录。
- API 关键词支持 GET／POST、参数与响应字段配置，可按待发货订单触发并联动确认发货。
- 对话内的卡券操作与后台卡券管理使用同一套数据。

## 对话操作示例

以下指令在「商品运营」中使用，素材路径、账号名、卡券名与价格替换为自己的设置。

| 目的 | 示例 |
| --- | --- |
| 研究商品 | `采集“示例商品”的Hot100` |
| 读取素材 | `我的素材在“/Users/your-name/Desktop/商品素材/商品A”` |
| 确认交付事实 | `确认：交付源码，包含教程，通过网盘发货` |
| 调整文案 | `用第2版，扩写详情，突出交付内容和使用步骤` |
| 定价 | `自动定价`、`最低成交价设为22元` |
| 调整素材 | `添加素材里的视频`、`用第2张图片做封面` |
| 制作封面 | `生成三套封面`、`使用第2套封面` |
| 选择账号 | `用“店铺A”发布` |
| 选择卡券 | `把当前商品绑定到卡券“示例交付”` |
| 新建卡券 | `新建卡券“示例交付”，发货内容：填写网盘链接与提取码` |
| 查看发布审核 | `发布当前商品`，核对后回复 `确认发布` |
| 多账号同步 | `同步发布到“店铺A、店铺B”`，核对后回复 `确认同步发布` |
| 管理排期 | `查看排期`、`查看发布日历`、`整批排期顺延一天` |
| 保存与恢复 | `保存当前版本“首轮审核通过”`、`查看商品版本`、`恢复上一版本` |
| 处理异常 | `查看运营待办`、`核对发布结果`、`查看上架差异` |
| 优化商品 | `刷新近7天经营数据`、`优化当前商品` |
| 暂停与继续 | `停止`、`继续`、`暂停整条任务`、`继续整条任务` |

批量排期示例：

```text
仍然卖示例商品，账号用店铺A，
/Users/your-name/Desktop/素材/第一天 明天20:00发布，
/Users/your-name/Desktop/素材/第二天 后天09:30发布，
先生成给我审核。
```

同一商品也可连续交代：

```text
应用经营模板“示例模板”，读取 /Users/your-name/Desktop/素材/商品A，
生成三套封面，使用第2套，明晚8点发布。
```
